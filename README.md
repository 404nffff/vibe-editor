# Vibe Editor

Vibe Editor 安装包与版本更新发布仓库。

## 下载

请从 [Releases](https://github.com/404nffff/vibe-editor/releases) 下载完整安装包。

Windows x64 v2 完整包包含 vibe-editor.exe、vibe-runtime.exe 和 release.json，三个文件须解压到同一目录后运行。

带平台名称的 release-v2-windows-amd64.json 和 vibe-runtime-v2-windows-amd64.exe 是自动更新附件。

本仓库维护发布说明与安装包，业务源码不在此仓库同步。
